# 🧸 Детская полка

Три детских приложения в одном месте. Работает без интернета и без установки:
откройте **`index.html`** двойным кликом — появится оглавление, из которого
ребёнок сам выбирает, чем заняться.

Чтобы дети заходили с телефона онлайн — см. **[PUBLISH.md](PUBLISH.md)**:
публикация на бесплатный GitHub Pages за пять минут.

## Что внутри

| | Приложение | Для чего | Возраст |
|---|---|---|---|
| 📖 | **Сказки** | Шесть историй про Луку и Давида с картинками и озвучкой | 3–7 |
| 🕐 | **Часики** | Учимся понимать время: стрелки, целые часы, половинки, минуты | 6–7 |
| 🎒 | **Умняшка** | Буквы, звуки, письмо по траектории, чтение, счёт и математика | 6–7 |

## Как пользоваться

1. Откройте `index.html`.
2. Внизу оглавления впишите имя ребёнка и выберите друга-помощника —
   это делается **один раз** и подхватывается всеми тремя приложениями.
3. Ребёнок нажимает на большую карточку. У каждой есть кнопка 🔊 —
   она расскажет вслух, что это за игра (полезно, если ребёнок ещё не читает).
4. Внутри любого приложения в левом нижнем углу есть кнопка 🏠 — возврат к оглавлению.
   Посреди урока она спросит подтверждение, чтобы занятие не прервалось случайно.

На карточках видно, где ребёнок остановился: сколько сказок прочитано,
какой уровень в «Часиках» и «Умняшке», сколько собрано звёзд.

## Как перенести на планшет

Скопируйте **всю папку целиком** — структура важна:

```
Детская полка/
├── index.html      ← это открывать
├── hub/            оглавление
├── shared/         общий профиль ребёнка
├── skazki/         сказки
├── chasiki/        часики
└── umnyashka/      буквы и математика
```

Если какой-то папки не окажется рядом, оглавление не сломается: карточка
станет серой и объяснит, что нужно сделать.

## Куда сохраняется прогресс

В браузер того устройства, где вы играете (LocalStorage). Отдельно у каждого
приложения; имя и персонаж — общие. При переносе на другое устройство
прогресс не переезжает, начнётся заново.

Если браузер запрещает сохранение (например, Safari при открытии файла),
приложения всё равно работают, а имя доедет до них через адрес страницы.

## Родителям

- В «Умняшке» есть отдельный раздел «Родителям» (защищён примером на сложение):
  время занятий, темы, слабые места и рекомендации.
- В «Часиках» — печатаемый диплом после экзамена.
- Лучше 5–10 минут каждый день, чем час раз в неделю.

## Разработчику

Ванильный JS без сборки. Оглавление — `hub/hub.js` + `hub/hub.css`,
общий профиль — `shared/profile.js` (имя, персонаж, сводки прогресса,
кнопка возврата). Приложение обнаруживается по файлу `app.info.js` в его папке:
это единственный способ проверить наличие файла, когда страница открыта
с `file://`.

Чтобы добавить четвёртое приложение: положите папку рядом, создайте в ней
`app.info.js` с вызовом `Hub.ready('id')`, допишите запись в массив `APPS`
в `hub/hub.js` и строку `<script src="id/app.info.js" onerror="...">` в `index.html`.

Тесты (jsdom):

```bash
node test/web-ready.js   # готовность к публикации в вебе — 11 проверок
npm install jsdom
node test/hub-smoke.js   # оглавление и связь трёх приложений — 20 проверок
node test/umn-smoke.js   # «Умняшка» — 21 проверка
node test/smoke.js       # «Часики»
node test/regress.js     # «Часики», регрессии — 24 проверки
```
