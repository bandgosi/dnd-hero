# 🎒 Умняшка — учимся читать и считать

Обучающая игра для детей 6–7 лет: чтение, письмо и математика.
Работает без интернета и без установки — откройте `index.html` двойным кликом.

## Как начать

1. Откройте папку `umnyashka` и дважды кликните `index.html`.
2. Ребёнок выбирает друга-помощника, взрослый вписывает имя.
3. Дальше можно ничего не настраивать: приложение само подберёт, что тренировать.

На планшете скопируйте папку на устройство и откройте `index.html` любым браузером.
Прогресс сохраняется в браузере — можно закрывать и продолжать в другой день.

## Что внутри

**📚 Читаем и пишем** — 17 уроков: знакомство с буквами → звуки → письмо букв
по траектории → слоги → чтение слов → предложения. Весь русский алфавит,
105 слов в словаре, 24 предложения.

**🔢 Математика** — 16 уроков: цифры → счёт до 5, 10, 20 → письмо цифр →
больше/меньше/равно → числовой ряд → сложение → вычитание → текстовые задачи.

**✍️ Письмо** — ребёнок ведёт пальцем по дорожке буквы: показана стартовая точка,
номер штриха и направление. Точность не требуется — важно движение.
Есть кнопка «Показать», а если совсем не получается — «Пока трудно», и урок идёт дальше.

**🎮 8 мини-игр:** 🧩 Собери слово · 🐝 Поймай букву · 🎨 Нарисуй букву ·
🐻 Накорми медведя · 🎈 Лопни ответ · 🚂 Математический поезд · 🚀 Запусти ракету ·
🏎 Гонка примеров. В каждой — настоящая учебная механика, результат идёт в прогресс.

**⚡ Тренировка дня** — 4 коротких задания на главном экране, всего на 5 минут.

## Чем это отличается от списка заданий

Приложение подстраивается под ребёнка. Для каждой буквы и каждого умения оно
хранит статистику: сколько раз показывали, сколько раз ответил верно, точность,
серию верных ответов. Дальше:

- буква, которая даётся хуже (точность ниже 70%), показывается заметно чаще;
- освоенная буква уходит на повторение через день, потом через два, четыре, неделю;
- ошибка возвращает материал в тренировку через 2–3 задания, в этом же уроке;
- следующий урок открывается, только когда предыдущий действительно сдан —
  на две звезды или при половине освоенных навыков;
- в вариантах ответа никогда не появляются буквы, которых ребёнок ещё не проходил.

## Для родителей

Вход — плитка «Родителям» на главном экране, защита примером на сложение.
Внутри: сколько времени ребёнок занимался за неделю, сколько заданий выполнил,
процент верных ответов, что изучает сейчас, освоение по темам,
список того, что даётся труднее всего, и рекомендации.

Там же — выгрузка отчёта в файл и сброс прогресса.

## Настройки

Имя · выбор помощника (лисёнок, совёнок, котёнок, робот) · звуки кнопок ·
голос помощника · анимации · скорость речи.

Голос читает все задания вслух через встроенный синтезатор речи браузера —
ребёнку не нужно уметь читать, чтобы понять, что делать. Если в браузере
голос недоступен, приложение честно об этом сообщит.

## Советы

- Лучше 5–10 минут каждый день, чем час раз в неделю.
- Первые разы посидите рядом: проговаривайте задания вслух вместе с голосом.
- Ошибка здесь не наказывается: первая неудача даёт подсказку, вторая —
  показывает ответ со словами «Запомним!». Слова «неправильно» в игре нет.
- Хвалите за старание, а не только за верный ответ.

## Разработчику

Архитектура, схемы данных и учебная программа — в `ARCHITECTURE.md`.
Ванильный JS без сборки; слои `data → core → tasks → screens/games`.
Новый тип задания добавляется одним вызовом `Tasks.register`, новая игра —
`Games.register`, без правок движка.

Тесты (jsdom, запускать из папки над проектом):

```bash
npm install jsdom
node test/umn-smoke.js     # интеграционный прогон: 21 проверка
```
