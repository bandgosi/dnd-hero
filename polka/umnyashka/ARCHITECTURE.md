# «Умняшка» — архитектура продукта

Обучающее веб-приложение для детей 6–7 лет — пять образовательных миров:
📚 чтение/письмо · 🔢 математика · 🚀 космос · 🎒 подготовка к школе · 🌍 окружающий мир.
Работает офлайн, без сборки и сервера: `index.html` открывается двойным кликом.

## Пять миров (v2)

Новые миры встроены в ту же архитектуру, а не приклеены сбоку:

- **трек** (`data/curriculum.js` → `TRACKS`) — мир главного экрана; юниты, навыки
  и SRS общие для всех пяти. Служебный трек `schoolday` скрыт (юниты режима
  «Школьный день»).
- **контент** — `data/space.js`, `data/school.js`, `data/world.js`: чистые данные,
  спроектированы и отревьюированы командой агентов (учитель начальных классов,
  эксперт по космосу, детский психолог, safety-ревьюер); правила формулировок
  зафиксированы в шапках файлов — не «упрощать» обратно.
- **механики** — `tasks/common.js` (`TaskKit`): answerBoard / orderBoard /
  pairBoard / memoryShow / findAll / teachCard. Типы миров (`tasks/space.js`,
  `tasks/school.js`, `tasks/world.js`) собирают задания из контента и TaskKit.
- **экраны** — `screens/worlds.js`: шапки карт (миссии космоса, школьный день,
  журнал), режим «Школьный день» (маршрут `schoolday`), «Журнал исследователя»
  (`collection`), «рюкзачок готовности» (5 категорий, считается из навыков).
- **коллекция** — `Store.addCard(id)` / `Store.data.collection`; карточки
  открываются на teach-шагах (животные, страны, планеты, профессии, транспорт,
  явления).
- **ежедневная миссия** — чтение + математика + один из новых миров
  (чередование по дням; мир со слабыми навыками идёт вне очереди) + письмо + игра.
- **тестовые метки** для автопрогона: `data-ok`, `data-answer` (orderBoard),
  `data-pair`, `data-t` (findAll), `data-step` (инструкции), `data-i` (звёзды),
  `data-items` (память). Не удалять — на них стоит регрессия.

## 1. Архитектура приложения

### Ключевое техническое решение (ADR-001)

**Выбрано:** ванильный JS в модульной файловой структуре, классические `<script>`.
**Отклонено:** React + TypeScript + Vite.

Причина: продукт должен открываться двойным кликом на планшете родителя — без
`npm install`, без dev-сервера, без сборки. ES-модули (`type="module"`) в Chrome
запрещены по CORS при открытии с `file://`, а собранный Vite-бандл требует HTTP-сервера.
Модульность при этом сохранена: каждый слой — отдельная папка, каждый модуль —
изолированный IIFE с единственным экспортом в глобальную область.
Миграция на React/TS возможна послойно: слои `data` и `core` не содержат DOM
и переносятся без изменений.

### Слои (зависимости только сверху вниз)

```
data/     чистый контент и генераторы заданий — без DOM и без состояния
   ↓
core/     состояние, адаптивное обучение, звук, роутер, базовый UI
   ↓
tasks/    движок заданий: рендер, проверка ответа, обратная связь
   ↓
screens/  экраны         games/  мини-игры
   ↓
app.js    сборка, регистрация маршрутов, запуск
```

Правила:
- `data/*` не знает ни о DOM, ни о прогрессе — чистые данные и функции;
- `core/store.js` — единственная точка правды о профиле; запись только через него;
- хранилище спрятано за адаптером `Storage` (`get/set/remove`) — замена на backend
  затрагивает один файл;
- аудио спрятано за фасадом `Speech`; c v3 ядро озвучки записано заранее:
  `audio/*.mp3` (205 клипов, нейроголос Piper ru_RU-irina, ~1 МБ) — названия
  и звуки букв, числа 0–20, весь словарь слов, похвала; реестр — `audio/clips.js`
  (`Speech.register`), `phrase()` ищет клип по нормализованному тексту, при
  отсутствии клипа (или запрете автоплея на iOS) договаривает синтезатор;
  динамика (слоги, задания с числами, реплики с именем) — всегда синтезатор,
  голос которого ребёнок выбирает в настройках;
- задания создаются только модулем `core/srs.js`, экраны их не выдумывают.

## 3. Система обучения

### Единица обучения — навык (skill)

Навык — это то, что можно измерить и повторить. Примеры идентификаторов:

```
letter:М        узнавание буквы М
sound:М         соотнесение буквы и звука
first:М         определение первого звука в слове
write:М         написание буквы М
syllable:МА     чтение слога
word:КОТ        чтение слова
sentence:3      сборка предложения
digit:7         узнавание цифры
count:5         пересчёт до 5
compare:10      сравнение в пределах 10
add:5           сложение в пределах 5
sub:5           вычитание в пределах 5
problem:add     текстовая задача на сложение
writeNum:7      написание цифры 7
```

### Цикл освоения

```
изучение → тренировка → повторение → проверка → закрепление
 (teach)    (practice)     (SRS)      (check)    (mastery)
```

- **изучение** — знакомство: большая буква, картинка, звук, показ траектории;
- **тренировка** — 3–5 разных типов заданий на этот же навык подряд;
- **повторение** — навык возвращается через интервал, зависящий от успеха;
- **проверка** — контрольные задания в конце юнита без подсказок;
- **закрепление** — навык считается освоенным при `accuracy ≥ 85%` и `streak ≥ 4`
  (серия именно подряд верных ответов, и считается результат ПЕРВОЙ попытки).

### Адаптивность (core/srs.js)

Задания **не** случайны. Очередь на каждый урок собирается так:

| доля | что берём | правило отбора |
|---|---|---|
| ~20% | новый материал | следующий неоткрытый навык юнита, если предыдущие освоены |
| ~50% | повторение по расписанию | `dueAt ≤ сейчас`, сначала самые «просроченные» |
| ~30% | слабые места | `accuracy < 70%` при `attempts ≥ 3`, сортировка по возрастанию accuracy |

Вес слабого навыка тем выше, чем ниже точность: буква с `accuracy 52%`
показывается примерно втрое чаще, чем буква с `accuracy 98%`.

### Интервальное повторение

Шесть ступеней: `10 минут → 1 день → 2 дня → 4 дня → 7 дней → 12 дней`.
Верхняя граница намеренно невелика: след памяти на букву у шестилетки
держится хуже, чем у взрослого.

- верный ответ → ступень +1, но только если навык «отлежался» (прошло не меньше
  60% текущего интервала): иначе четыре ответа за минуту отправляли букву на две недели;
- ошибка → ступень уменьшается на 2 (не ниже 0), навык возвращается в тренировку
  в этом же уроке через 2–3 задания;
- сложность задания внутри навыка растёт отдельно: `L1` (выбор из 2) →
  `L2` (выбор из 4) → `L3` (без подсказки/на время).

## 4. Система прогресса

Раздельный учёт по двум блокам и по разделам внутри них:

```
ЧТЕНИЕ:     буквы · звуки · слоги · слова · предложения · письмо букв · письмо слов
МАТЕМАТИКА: цифры · счёт · сравнение · сложение · вычитание · задачи · письмо цифр
```

- **звёзды** — 0–3 за юнит, зависят от доли ответов с первой попытки;
- **проценты раздела** — доля освоенных навыков раздела, показывается как `⭐⭐⭐⭐☆ 80%`;
- **уровень блока** — открывается по мере освоения юнитов;
- **XP и уровень профиля** — общая шкала с растущей стоимостью уровня;
- **серия дней** 🔥 — календарные дни подряд с завершённой тренировкой;
- **достижения** 🏆 — 24 штуки, у каждой есть точка выдачи в коде;
- **награды** 🎁 — предметы персонажу (шапки, очки, рюкзаки, фоны, питомцы),
  открываются за освоение разделов, а не за количество кликов.

Мотивация построена на видимом прогрессе: экран «Мои успехи» показывает
не только награды, но и что именно ребёнок теперь умеет.

## 6. Компоненты

**Базовые (core/ui.js):** `Button` (5 вариантов, 3 размера), `IconButton`, `Card`,
`BigCard` (блок обучения), `Chip`, `Stars`, `ProgressBar`, `Modal`, `Toast`,
`Field`, `Switch`, `Segmented`, `Screen`, `TopBar`, `Sheet` (нижняя панель).

**Продуктовые:** `MascotBubble` (персонаж + реплика + озвучка), `LetterCard`,
`SoundButton` 🔊, `TileGrid` (варианты ответа), `TraceCanvas` (письмо),
`SyllableTile`, `WordBuilder`, `SentenceBuilder`, `CountGroup` (предметы для счёта),
`NumberLine`, `CompareScale` (весы для больше/меньше), `EquationRow`,
`SkillBar` (раздел прогресса), `RewardCard`, `DailyPlan`, `ParentChart`.

**Экраны:** 10 штук (см. карту экранов). **Игры:** 8 штук.
