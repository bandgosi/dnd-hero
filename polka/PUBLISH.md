# Как выложить «Детскую полку» в интернет

Сайт полностью статический, поэтому подойдёт бесплатный GitHub Pages.
Репозиторий уже собран и закоммичен — осталось отправить его на GitHub
и включить публикацию. Занимает пять минут.

---

## Шаг 1. Создать пустой репозиторий на GitHub

1. Откройте <https://github.com/new>.
2. **Repository name** — например `detskaya-polka`.
3. **Public** (для Pages на бесплатном тарифе нужен публичный репозиторий).
4. Ничего не добавляйте: ни README, ни .gitignore, ни лицензию —
   иначе при первой отправке возникнет конфликт.
5. Нажмите **Create repository**.

## Шаг 2. Отправить файлы

Откройте Терминал и выполните, подставив свой логин и имя репозитория:

```bash
cd ~/Downloads/detskaya-polka
git remote add origin https://github.com/ВАШ-ЛОГИН/detskaya-polka.git
git push -u origin main
```

GitHub попросит логин и пароль. **Вместо пароля нужен токен**: обычные пароли
для командной строки давно отключены.

<details>
<summary>Где взять токен (30 секунд)</summary>

1. <https://github.com/settings/tokens> → **Generate new token (classic)**.
2. Note: `detskaya-polka`, срок — на ваше усмотрение.
3. Отметьте единственную галочку **repo**.
4. **Generate token**, скопируйте строку `ghp_…`.
5. В Терминале вставьте её в ответ на запрос пароля (символы не отображаются — это нормально).

Проще всего один раз установить [GitHub CLI](https://cli.github.com):
тогда `gh auth login` избавит от токенов, а весь второй шаг сведётся к
`gh repo create detskaya-polka --public --source=. --push`.
</details>

## Шаг 3. Включить GitHub Pages

1. В репозитории: **Settings** → слева **Pages**.
2. **Source**: `Deploy from a branch`.
3. **Branch**: `main`, папка `/ (root)` → **Save**.
4. Подождите 1–2 минуты и обновите страницу — вверху появится адрес.

Адрес будет такой:

```
https://ВАШ-ЛОГИН.github.io/detskaya-polka/
```

---

## Шаг 4. Дать детям

**Android (Chrome):** откройте адрес → меню ⋮ → «Добавить на главный экран».
**iPhone (Safari):** откройте адрес → «Поделиться» → «На экран „Домой"».

Появится иконка с книжками, приложение откроется на весь экран без адресной
строки — как обычная игра. Иконка и название уже настроены.

Полезно сразу открыть страницу и вписать имя ребёнка — оно подхватится
всеми тремя приложениями.

---

## Что важно знать

**Прогресс хранится в браузере устройства.** На телефоне и на планшете он
будет свой. Если ребёнок откроет сайт в другом браузере — начнёт заново.
Это плата за отсутствие сервера и регистрации.

**Не очищайте данные сайта** в настройках браузера — вместе с ними исчезнут
звёзды и пройденные уроки.

**Репозиторий публичный** — сказки и приложения увидит любой, у кого есть
ссылка. Личных данных внутри нет: имя ребёнка хранится только на его
устройстве и никуда не отправляется.

**Голос** работает через встроенный синтезатор речи браузера. На Android
и iPhone русский голос есть по умолчанию. Если ребёнок не слышит озвучку,
проверьте, что телефон не в беззвучном режиме.

## Как обновить сайт потом

Меняете файлы в папке и отправляете снова:

```bash
cd ~/Downloads/detskaya-polka
git add -A
git commit -m "Что изменилось"
git push
```

Через минуту обновление появится онлайн. Если у ребёнка старая версия
осталась в кэше — потяните страницу вниз для обновления.

---

## Проверка перед публикацией

В папке лежат тесты. Перед отправкой изменений полезно прогнать:

```bash
cd ~/Downloads/detskaya-polka
node test/web-ready.js    # готовность к вебу: пути, регистр букв, иконки
npm install jsdom
node test/hub-smoke.js    # оглавление и связь трёх приложений
node test/umn-smoke.js    # «Умняшка»
node test/smoke.js        # «Часики»
node test/regress.js      # «Часики», регрессии
```

`test/web-ready.js` ловит главную ловушку переезда на сервер: macOS не
различает заглавные и строчные буквы в именах файлов, а GitHub — различает.
Ссылка `Styles/base.css` работает на вашем компьютере и отдаёт 404 онлайн.
