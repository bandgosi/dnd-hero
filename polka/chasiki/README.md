# 🕐 Часики — учимся понимать время

Обучающая веб-игра для детей 6–7 лет. Полностью офлайн: откройте `index.html` двойным
кликом — сервер не нужен, внешних библиотек нет.

## Как запустить

1. Откройте папку `chasiki`.
2. Дважды кликните `index.html` (Chrome, Safari, Edge, Firefox).
3. На планшете/телефоне: скопируйте папку на устройство или откройте через любой файловый менеджер.

Прогресс сохраняется в браузере (LocalStorage) — можно закрывать и продолжать позже.

## Структура

```
chasiki/

├── styles/
│   ├── base.css          переменные, шрифты, фон (небо, облака)

    ├── audio.js          все звуки через Web Audio API (без файлов)
    ├── fx.js             конфетти, салют, дождь наклеек на <canvas>
    ├── clock.js          SVG-часы: анимация, перетаскивание стрелок
    ├── ui.js             элементы, роутер экранов, модалки, тосты
    ├── curriculum.js     10 уроков и генераторы заданий
    ├── lessons.js        движок урока и обучающие анимации
    ├── games.js          5 мини-игр
    └── app.js            экраны приложения и запуск
```

## Программа обучения

| Уровень | Тема | Чему учит |
|---|---|---|
| 1 | Короткая стрелка | часовая стрелка, «покажи 3 часа» |
| 2 | Длинная стрелка | круг = 60 минут, цифра = 5 минут |
| 3 | Целые часы | 1:00, 7:00, 11:00 |
| 4 | Половина часа | 3:30, 8:30 и почему часовая «между» цифрами |
| 5 | Четверть часа | :15 и :45 через сектор циферблата |
| 6 | Любое время | 2:10, 6:25, 4:40, 9:55 |
| 7 | Соедини часы | аналоговые ↔ цифровые |
| 8 | Поставь стрелки | ребёнок сам выставляет время |
| 9 | Сколько времени? | чтение вразнобой |
| 10 | Экзамен | 20 заданий → медаль, диплом, конфетти |

Мини-игры: 🎈 Лопни время • 🚂 Часовой поезд • 🧩 Собери часы • 🎯 Попади стрелкой • 🏁 Гонка со временем.

## Настройки (⚙️)

- имя ребёнка (попадает в диплом);
- звук вкл/выкл;
- анимации вкл/выкл (щадящий режим);
- «открыть все уровни» — для родителя, если нужно потренировать конкретную тему;
- сложность: 🐣 просто (целые часы и полчаса) • 🙂 обычно (шаг 5 минут) • 🔥 сложно (любая минута);
- сброс прогресса.

## Советы родителю

- Первый заход лучше пройти вместе: экран «Как устроены часы» позволяет тыкать в детали
  и слушать объяснение.
- Начните со сложности «просто», переключитесь на «обычно» после урока 5.
- Ошибка никогда не наказывает: после второй попытки игра сама показывает верный ответ.
- Ежедневная серия (🔥) считается по календарным дням — удобно как ритуал по 10 минут в день.

## Проверка

Рядом с папкой проекта лежат два набора тестов, прогоняющих приложение в jsdom:

- `test/smoke.js` — базовый: математика стрелок, генерация вариантов ответа,
  прохождение урока, запуск всех мини-игр и экранов (26 проверок);
- `test/regress.js` — регрессионный: сектор полного круга, прерывание анимации стрелок,
  двойной тап по кнопкам, звёзды за ответы с первой попытки, достижимость заданий на всех
  уровнях сложности, отсутствие «зомби-таймеров» после выхода из игры, устойчивость
  к повреждённой записи в хранилище (24 проверки).

```bash
npm install jsdom
node test/smoke.js
node test/regress.js
```
